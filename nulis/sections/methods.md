# Methods

Fungsi retoris berbeda per paradigma — pakai istilah mutu yang benar:
- **Kuantitatif** → tujuan: *reproducibility*. Baca `../research-types/quantitative.md`.
- **Kualitatif** → tujuan: *methodological integrity / trustworthiness*. Baca `../research-types/qualitative.md`.
- **Mixed** → keduanya + narasi integrasi. Baca `../research-types/mixed-methods.md`.

Isi rinci ditentukan **reporting guideline sesuai desain studi** (CONSORT untuk RCT, STROBE observasional, PRISMA review sistematis, COREQ/SRQR kualitatif, JARS-Mixed/GRAMMS mixed). EQUATOR Network (equator-network.org) mengindeks 700 guideline dan bisa difilter per desain & per section — bila desain user tidak tercakup file research-types, cari di sana.

## Struktur umum sub-bagian (sesuaikan konvensi jurnal)
1. Desain studi / pendekatan (+ justifikasi)
2. Partisipan/sampel/data — kriteria, ukuran, cara rekrutmen/pengumpulan; kuantitatif: dasar penentuan ukuran sampel (power analysis)
3. Instrumen/material/apparatus — validitas & reliabilitas instrumen (kuanti) / kredibilitas protokol (kuali)
4. Prosedur — cukup detail untuk direplikasi (kuanti) atau diaudit (kuali)
5. Analisis data — teknik + software + asumsi yang diuji
6. Etika — persetujuan komite etik, informed consent (wajib untuk riset subjek manusia/hewan)

## Prinsip narasi
- **Bukan resep datar**: setiap pilihan metodologis penting diberi justifikasi singkat ("X was chosen because..."). Ini yang membedakan naskah Q1 dari laporan teknis.
- Tense: past tense ("Participants were recruited...", "We measured...").
- Voice: pasif atau "we" — konsisten; ikuti kebiasaan jurnal target.
- Detail yang mengganggu alur (kuesioner lengkap, derivasi panjang, parameter tuning) → lampiran/supplementary.
- Subjek manusia: laporkan demografi secukupnya; ikuti JARS-REC untuk pelaporan ras/etnis/budaya.

## Checklist audit
- [ ] Desain sesuai dan mampu menjawab RQ (alignment RQ ↔ metode — cek `../coherence.md`)
- [ ] Semua item guideline yang relevan terlaporkan (jalankan checklist COREQ/CONSORT/dll. bila ada)
- [ ] Pilihan-pilihan kunci dijustifikasi
- [ ] Cukup detail untuk replikasi/audit, tanpa menenggelamkan pembaca
- [ ] Pernyataan etika ada (bila riset subjek manusia/hewan)
